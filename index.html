03 / the framework

AsenaJS

A high-performance IoC web framework for Bun, bringing Spring Boot's automatic component discovery and field-based dependency injection to TypeScript. Controllers, services, middleware and WebSockets are plain decorated classes; the HTTP layer is a pluggable adapter.

  • 100+stars on the core
  • 300+commits on the core
  • 24releases
  • 15repositories
@Service()
class GreetingService {
  greet(name: string) {
    return `Hello ${name}`;
  }
}

@Controller('/')
class HelloController {
  @Inject(GreetingService)
  private greetingService: GreetingService;

  @Get('/')
  async hello(context: Context) {
    return context.send(this.greetingService.greet('asena'));
  }
}

06 / I love my granny

Granny

Granny takes a plan and turns it into a PR-ready branch. An implementer agent builds it stage by stage, reviewers check every stage in parallel, and a judge decides which findings are worth fixing. The loop repeats until the review is clean. Nothing is pushed: you get a branch, a PR body and a short report, and you decide what happens next.

  • 4agent hosts
  • 4rounds at most
  • 70fix threshold
  • 0pushes
$ npx skills add LibirSoft/grannyFlow

> granny setup
> plan OAuth login with granny on feat/oauth
> implement plans/auth/plan.md with granny
> granny judge

The judge rates impact, likelihood and fix cost, and code turns that into a priority. Critical and major findings are always fixed, the rest only above the threshold, and whatever is left comes back to you with the reason. On Claude Code, opencode and omp the loop runs as code, so the round cap holds on every run. On Cursor the agent follows the same steps by hand.
